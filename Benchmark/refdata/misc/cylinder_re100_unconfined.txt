# Unconfined 2D laminar flow past a circular cylinder, Re = U*D/nu = 100

# [S1] Strouhal-Reynolds fit (Williamson). Verbatim from Beaudan & Moin (1994), "Numerical Experiments on the Flow Past a
#      Circular Cylinder at Sub-Critical Reynolds Number", Stanford TF-62, p.2, Eq. (1):
#      https://web.stanford.edu/group/tfsa/TF_reports/TF-062_Beaudon.pdf
#   "A least-squares curve-fit of the Strouhal curve for Reynolds numbers between 50 and 180 is given by
#      St = A/ Re + B + C Re   (1)
#    where A= -3.3265, B = 0.1816 and C = 1.6 x 10-4 (Williamson 1991)."
#   Beaudan & Moin cite: Williamson, C.H.K. 1991 "Sinuous and varicose gridlines in the cylinder wake", Phys. Fluids A 3, 1427-1428.
#   The same coefficients appear in Basilisk sandbox code cylinder-strouhal.c attributed to Williamson (1988)
#   "Defining a universal and continuous Strouhal-Reynolds number relationship for the laminar vortex shedding of a circular
#   cylinder", Phys. Fluids 31, 2742-2744: "f(x) = -3.3265/x + 0.1816 + 1.6e-4*x"
#   https://basilisk.dalembert.upmc.fr/sandbox/ghigo/src/test-navier-stokes/cylinder-strouhal.c?raw=
#   NOTE: this is an EXPERIMENTAL (parallel-shedding, 3D-span) fit; at Re=100 it evaluates to 0.1643 (computed here, not quoted).
#   Valid range quoted: 50 <= Re <= 180.
#
# [S2] Comparison table at Re = 100, verbatim Table 1 of Qu, Norberg, Davidson, Peng & Wang (2013) "Quantitative numerical
#      analysis of flow past a circular cylinder at Reynolds number between 50 and 200", J. Fluids Struct. 39, 347-370.
#      https://publications.lib.chalmers.se/records/fulltext/180053/local_180053.pdf  (fetched twice, identical)
