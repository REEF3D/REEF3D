# ===== 4.1.1 Dam break on a wet domain without friction (Stoker) =====
# Initial: h = hl for 0 <= x <= x0, h = hr for x0 < x <= L, hl >= hr, u = 0.
# h(t,x) = hl                                          x <= xA(t)            [inferred]
#        = (4/(9g)) (sqrt(g hl) - (x - x0)/(2t))^2     xA(t) <= x <= xB(t)   [inferred]
#        = cm^2 / g                                    xB(t) <= x <= xC(t)   [inferred]
#        = hr                                          xC(t) < x             [inferred]
# u(t,x) = 0                                           x <= xA(t)
#        = (2/3) ((x - x0)/t + sqrt(g hl))             xA(t) <= x <= xB(t)
#        = 2 (sqrt(g hl) - cm)                         xB(t) <= x <= xC(t)
#        = 0                                           xC(t) <= x
# xA(t) = x0 - t sqrt(g hl)
# xB(t) = x0 + t (2 sqrt(g hl) - 3 cm)
# xC(t) = x0 + t * 2 cm^2 (sqrt(g hl) - cm) / (cm^2 - g hr)
# cm = sqrt(g hm) is the solution of:  -8 g hr cm^2 (sqrt(g hl) - cm)^2 + (cm^2 - g hr)^2 (cm^2 + g hr) = 0

# ===== 4.2.1 Planar surface in a parabola without friction (Thacker, 1D reduction) =====
# z(x) = h0 ( (1/a^2) (x - L/2)^2 - 1 )
# Initial: h(x) = -h0 ( ( (1/a)(x - L/2) + B/sqrt(2 g h0) )^2 - 1 ) for x1(0) <= x <= x2(0), 0 otherwise; u(x) = 0

# ===== 4.2.2 Two-dimensional cases (Thacker) =====
# Topography (17): z(r) = -h0 (1 - r^2/a^2),  r = sqrt((x - L/2)^2 + (y - L/2)^2), (x,y) in [0,L]x[0,L]
# -- Radially-symmetrical paraboloid --
# h(r,t) = h0 ( sqrt(1 - A^2)/(1 - A cos(w t)) - 1 - (r^2/a^2) ( (1 - A^2)/(1 - A cos(w t))^2 - 1 ) ) - z(r)
# u(x,y,t) = 1/(1 - A cos(w t)) * (1/2) w (x - L/2) A sin(w t)
# v(x,y,t) = 1/(1 - A cos(w t)) * (1/2) w (y - L/2) A sin(w t)

# ===== Solitary wave (Synolakis 1987 canonical beach problem) =====
# [P1] Synolakis et al. (2008) PAGEOPH 165, "Validation and verification of tsunami numerical models",
#      https://nctr.pmel.noaa.gov/Pdf/PAGEOPH_Synolakis_etal_2008.pdf  (raw extraction, verbatim):
#   "eta(x, t = 0) = H sech^2[c(x - Xs)] where c = sqrt(3H/4) and H is the dimensionless wave height, i.e., H = H~/d~."
#   "Xs = X0 + (1/c) arccosh sqrt(20)"
#   NOTE: the symbol printed as 'c' here is gamma in the NOAA benchmark page
#   (https://nctr.pmel.noaa.gov/benchmark/Laboratory/Laboratory_CanonicalBathymetry/index.html):
#   "gamma = sqrt(3(H~/d~)/4)", "X_s = X_0 + (L/2)", "L/2 = (1/gamma) arccosh sqrt(20)"   (x, eta, H scaled by depth d)
#   Dimensional form (DERIVED here by rescaling, not quoted): eta = H sech^2( sqrt(3H/(4 d^3)) (x - Xs) )
# [P2] Celerity c = sqrt(g (d + H)): verbatim code from Basilisk beach.c, https://basilisk.fr/src/test/beach.c?raw
#   double c = sqrt(G*(1. + A)*h0), psi = x - c*t;
#   double k = sqrt(3.*A*h0)/(2.*h0*sqrt(h0*(1. + A)));
#   return A*h0*sech2 (k*psi);
#   ... u.x[] = c*eta/(h0 + eta);
#   L = 2./k*acosh(sqrt(1./0.05));
#   (A = H/h0; Basilisk's k includes a 1/sqrt(1+A) factor, i.e. (algebra done here) k = sqrt(3A/(4 h0^2 (1+A))), unlike gamma in [P1].)
#   Basilisk cites Yamazaki et al. 2009 for this setup.
