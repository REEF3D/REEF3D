# CORAL: linear/

Linear analysis of a CORAL model.

## Planned content

* eigenvalues and mode shapes of the structure, free or about a deformed state
* linearisation of the full model about an operating point (structure, aero, hydro, control)
* Campbell diagrams over rotor speed
* multi-blade coordinate transform
* linear state-space models for controller design
