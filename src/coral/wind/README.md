# CORAL: wind/

Wind inflow.

## Planned content

* steady wind with power-law or logarithmic shear and veer
* IEC 61400-1 deterministic events: EOG, EDC, ECD, EWS, ETM/EWM
* turbulence generation: Kaimal spectrum with coherence, Mann model
* interpolation of the wind field in space and time at blade and tower points
* CORAL's own binary format for generated fields
